# Liquid Glass Design - Full Stack Platform

Welcome to the **Liquid Glass Design** project, a premium full-stack ecosystem designed to deliver an immersive, fluid, and high-performance digital experience. This project combines a scalable **NestJS Microservices** backend with a state-of-the-art **React 19** frontend, utilizing the latest web technologies and AI-enhanced development workflows.

---

## 🌊 Project Vision: The Fluid Sanctuary

The core philosophy of this project is to create "Digital Atmospheres" rather than just interfaces. We leverage **Glassmorphism**, **Liquid Motion**, and **Atmospheric UI** to build digital environments that react and adapt to human intuition.

---

## 🏗️ Technical Architecture

The codebase is organized as a multi-module repository covering backend services, frontend applications, and design assets.

### 1. Backend (`/backend`)
A production-ready **NestJS** microservices architecture managed with **Nx Monorepo**.
- **Framework**: [NestJS](https://nestjs.com/)
- **Communication**: gRPC for high-performance inter-service messaging.
- **Database**: PostgreSQL with TypeORM.
- **Key Modules**: API Gateway, Common Library, Database Layer.

### 2. Frontend React (`/frontend`)
The primary immersive user interface built with the most modern React stack.
- **Framework**: [React 19](https://react.dev/)
- **Bundler**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (CSS-first engine)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Design System**: Liquid Glass Design (custom glass panels, fluid orbs, and bento grids).

### 3. Frontend Nuxt (`/frontend-nuxt`)
An alternative frontend implementation using Nuxt.js for SSR capabilities and flexible delivery.

### 4. Design Assets (`/.stitch`)
Original **Stitch** design sources, including high-fidelity HTML and screenshots used for automated component generation.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v20+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/quanghung97/test-vibe-coding.git
   cd test-vibe-coding
   ```

2. **Frontend Setup**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   Access the UI at `http://localhost:5174/`

3. **Backend Setup**:
   ```bash
   cd ../backend
   npm install
   npm run start:dev
   ```
